## 🎭 核心演示流程

### 第一幕：游客文本问答（2-3分钟）

**场景**: 游客通过文字提问了解景点

**演示步骤**:

1. **演示景点事实查询**
   ```
   Q: 灵山大佛有什么特色？
   A: 灵山大佛高88米，是无锡的标志性景点。佛体由青铜铸造，莲花座庄严殊胜。
   ```

2. **演示历史文化询问**
   ```
   Q: 请介绍一下梵宫的建筑特色？
   A: 梵宫建筑精妙绝伦，融合了传统佛教艺术与现代建筑技术。内部供奉众多佛像，文化瑰宝。
   ```

3. **演示路线推荐**
   ```
   Q: 我想游览2小时，有什么推荐的路线吗？
   A: 推荐您走"历史文化爱好者路线"。该路线包含灵山大佛、梵宫、五印坛城等核心点位，预计游览时间约2小时。
   ```

### 第二幕：游客语音问答（2-3分钟）

**场景**: 游客通过语音提问

**演示步骤**:

1. **唤醒数字人**
   - 点击"开始语音对话"按钮
   - 系统提示："您好，我是灵山胜境的AI导游，请问有什么可以帮您的？"

2. **语音提问1**
   ```
   用户: 九龙灌浴有什么表演？
   系统: 九龙灌浴每天定时进行音乐喷泉表演，非常壮观。
   ```

3. **语音提问2**
   ```
   用户: 门票多少钱？
   系统: 成人票XX元，学生票XX元。温馨提示：价格如有调整，以景区当日公告为准。
   ```

### 第三幕：路线规划推荐（2分钟）

**场景**: 根据游客偏好生成个性化路线

**演示步骤**:

1. **打开路线推荐页面**
   - 选择兴趣：历史文化
   - 选择时长：2小时
   - 选择人群：情侣

2. **系统推荐结果**
   ```
   推荐路线：历史文化爱好者路线

   推荐理由：
   ✓ 符合您的"历史文化"兴趣偏好
   ✓ 官方路线匹配度92%
   ✓ 包含5个核心点位
   ✓ 预计游览时间约2小时

   游览顺序：灵山大佛 → 梵宫 → 五印坛城 → 祥符禅寺 → 胥山大广场

   温馨提示：建议上午9点开始，避开人流高峰
   ```

### 第四幕：评测中心展示（2分钟）

**场景**: 向评委展示系统准确率

**演示步骤**:

1. **打开评测中心**
   - 显示100题评测集
   - 点击"运行评测"

2. **评测结果展示**
   ```
   总准确率: 92.5% ✓
   未命中拒答率: 96.0% ✓
   来源完整率: 98.5% ✓

   分类准确率:
   - 景点事实: 93.3%
   - 历史文化: 91.3%
   - 官方路线: 93.3%
   ```

## 🚨 应急处理

### 常见问题及应对

**问题1**: TTS无声音
- **检查**: 音量是否打开
- **检查**: TTS服务是否启动
- **备用**: 使用文字回答继续演示

**问题2**: 回答不准确
- **应对**: 说明"这是AI基于资料库的实时回答，可能会有些许差异"
- **后续**: 可展示评测中心的高准确率数据

**问题3**: 响应慢
- **说明**: 首次提问需要加载索引，后续会很快
- **展示**: 重复提问同一问题展示缓存加速

## 🎯 如何测试Week 1组件

### 步骤1：打开应用

1. 在浏览器中打开：`http://localhost:3000/`
2. 应用默认会显示 **ScenicGuideShell**（灵山胜境AI导游）

### 步骤2：查看Tab标签页

在页面顶部你会看到两个Tab：
- **问答** - 原有的问答功能
- **路线推荐** - 新开发的路线规划功能 ⭐

### 步骤3：测试路线推荐功能

#### 3.1 切换到"路线推荐"标签页

点击"路线推荐"标签，应该看到：
- 📋 路线规划面板（RoutePlannerPanel）
- 🎨 精美的表单设计
- ✅ 各种偏好选择选项

#### 3.2 填写路线偏好

**必填项**：
1. **兴趣偏好**（至少选一个）：
   - ☑️ 历史文化
   - ☑️ 自然风光
   - ☑️ 亲子互动
   - ☑️ 拍照打卡
   - ☑️ 轻松休闲

2. **游览时长**：
   - 1小时 / 2小时 / 半日 / 一日

**可选项**：
3. **同行人群**：个人 / 情侣 / 亲子 / 老人 / 研学团队
4. **体力偏好**：轻松 / 适中 / 充实
5. **特殊需求**：无障碍 / 雨天 / 少排队 / 餐饮优先

#### 3.3 生成路线

1. 选择至少一个兴趣偏好
2. 点击"**生成推荐路线**"按钮
3. 应该看到：
   - 🔄 加载动画（1.5秒）
   - ✅ 成功提示："路线推荐已生成！"
   - 🎯 路线结果卡片（RouteResultCard）

#### 3.4 查看路线结果

路线结果卡片应该显示：
- 📍 路线名称："历史文化深度游（2小时精简版）"
- 🏆 匹配度：92%
- ⏱️ 基本信息：
  - 时长：120分钟
  - 人群：个人
  - 体力：适中
  - 景点数：3个
- 💡 推荐理由：
  - ✓ 您选择的偏好
  - ✓ 匹配度说明
  - ✓ 景点特色
- 📋 行程安排���
  1. **灵山大佛**（50分钟）- 佛教文化体验的核心
  2. **祥符禅寺**（40分钟）- 千年古刹的历史沉淀
  3. **灵山梵宫**（30分钟）- 佛教艺术的卢浮宫
- 📚 来源说明
- 🔄 "重新规划路线"按钮

#### 3.5 重置路线

点击"重新规划路线"按钮，应该：
- 返回到路线规划面板
- 清空之前的输入
- 可以重新选择偏好
